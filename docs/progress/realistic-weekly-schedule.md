## ⏰ Time Management Tips

### Maximize Weekday Evenings (3-4 hours):
1. **Before starting:** Clear workspace, close distractions
2. **First 5 min:** Review today's tasks from plan
3. **Next 2 hours:** Deep focus on Priority 1 task
4. **15 min break:** Stretch, walk, hydrate
5. **Next 1-1.5 hours:** Priority 2 task or continue Priority 1
6. **Last 15 min:** Save work, plan tomorrow

### Maximize Weekends (8 hours/day):
1. **Morning session (4 hours):** Hardest/most important work
2. **Lunch break (1 hour):** Proper meal, walk outside
3. **Afternoon session (4 hours):** Secondary tasks, testing, polish
4. **Evening:** STOP WORKING, rest, recharge

### When You're Tired:
- Do easier tasks (testing, formatting, reviewing)
- Don't try to write new content when exhausted
- Take breaks every 90 minutes minimum
- Sleep is more valuable than extra work hours

### Red Flags to Watch:
- Working past 23:00 on weekdays
- Skipping meals or breaks
- Working >8 hours on weekends
- Feeling burned out
- Quality declining

**If you see red flags:** Take a break. Quality > Quantity.

## 🆘 When You Need Help

### If Running Behind Schedule:
1. **Prioritize ruthlessly:** Evaluation chapter + web app are mandatory
2. **Cut optional features:** Simplify web app to basics only
3. **Reduce word targets:** You're already over 13,000 total
4. **Use weekends strategically:** Can catch up on weekends

### If Stuck on Technical Issues:
- Web app: Use Streamlit examples as template
- Code bugs: Document and move on, mention in limitations
- Missing data: Work with what you have

### If Stuck on Writing:
- Write rough draft first, polish later
- Use bullet points, expand to paragraphs
- Reference similar papers for structure
- Get supervisor feedback if needed
