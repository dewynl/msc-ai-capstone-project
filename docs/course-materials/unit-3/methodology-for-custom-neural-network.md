# Methodology for Custom Neural Network for Automated Course Syllabus Generation

## **Selected Approach**

This project will be structured as a Software Development project, using Agile for iterative development, while aligning CRISP-DM stages like data preparation and modeling to guide ML tasks. Rather than following a traditional research approach with research questions, I'll be focusing on engineering aims and objectives to develop a functional AI system.

## **Justification**

The Software Development approach is appropriate because the core deliverable is a custom neural network architecture - a complex software artifact that requires iterative development and testing. I've chosen Agile methodology because it provides the flexibility needed when developing novel AI systems where outcomes are uncertain. Unlike a plan-driven approach that requires complete specifications upfront, Agile allows me to adapt as new challenges emerge during model development.

As noted in the course materials, Agile emphasizes "delivering key functionality early and often" which is essential when building machine learning models that require multiple iterations to refine. This approach will let me develop a minimal working prototype early, then progressively enhance its capabilities through continuous testing and improvement.

## **Data Collection and Implementation Strategy**

For this Software Development project, I'll collect syllabus data from the Open Syllabus Project API and other open educational resources. This data will be processed and used to train the custom neural network. The implementation will follow four main phases: data preprocessing, model architecture development, training and optimization, and evaluation.

The data preprocessing phase will involve cleaning and standardizing syllabus data before creating structured training formats. Once the data is prepared, I'll develop the custom model architecture with specialized embedding layers for educational terminology and sequence-to-sequence components. After building the initial model, I'll conduct extensive training and optimization through hyperparameter tuning and iterative refinement.

Each phase will produce concrete deliverables: a processed dataset, a functional model architecture, a trained model, and comprehensive evaluation results. By following this Agile Software Development approach, I can adapt to challenges as they arise and ensure the final system effectively generates coherent course syllabi.
