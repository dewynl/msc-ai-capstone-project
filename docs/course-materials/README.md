# Course Materials

This directory contains weekly materials from MSc AI capstone project course sessions.

## Organization

Course materials are organized into unit-specific subdirectories:
- `unit-1/` - Introduction to Dissertation
- `unit-2/` - Project Planning and Risks  
- `unit-3/` - Project Types and Research Methods
- `project-proposal.md` - Main project proposal document

Each unit follows the naming convention: `unit-XX-topic-name.md`

## File Structure

Each unit directory includes:
- **Main unit content**: `unit-XX-topic-name.md` - Core course material
- **Additional materials**: Supporting documents, outlines, methodologies
- **Course Information**: Unit number, date, topic embedded in content
- **Notes**: Key takeaways and important points
- **Action Items**: Tasks, assignments, and preparation work

## Usage

### Adding New Units
1. Create a new unit directory: `unit-XX/`
2. Create main content file: `unit-XX-topic-name.md`
3. Add any supporting materials with descriptive names
4. Update this README with links to new content

### File Naming Convention
- **Directories**: `unit-XX` (two-digit numbers)
- **Main content**: `unit-XX-topic-name.md`
- **Supporting files**: `descriptive-name.md` (lowercase, hyphens)
- **No spaces, special characters, or hash suffixes**

### Manual Editing Tips
- Use proper markdown heading hierarchy (##, ###, ####)
- Add emphasis to key concepts with **bold** or *italic*
- Break up long paragraphs for readability
- Add cross-references between units
- Include relevant links or resources
- Use lists for structured information

## Integration with Project

These course materials support the overall capstone project by:
- Providing structured guidance for dissertation development
- Tracking academic requirements and deadlines
- Maintaining continuity between weekly sessions
- Supporting project planning and methodology development
- Creating a searchable knowledge base of course content
