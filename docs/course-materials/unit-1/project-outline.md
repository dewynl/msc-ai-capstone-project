# MSc Artificial Intelligence Project Outline - One Pager

## **Research Area and Working Title**

**Research Area:** AI in Education, Custom Neural Networks for Educational Content Generation

**Working Title:** Custom Neural Network Architecture for Automated Course Syllabus Generation

## **Proposed Research Problem and Research Question**

**Problem:** Course syllabus creation requires domain expertise and significant manual effort. Current AI approaches lack educational coherence or need extensive human intervention. There's a gap in custom machine learning solutions designed specifically for structured educational content generation.

**Research Question:** "How can a custom machine learning model effectively generate structured, coherent course syllabi from minimal input context?"

## **Proposed Aims and Objectives**

**Primary Aim:** Develop and evaluate a custom machine learning model that generates educationally sound, structured course syllabi from minimal input.

**Objectives:**

1. Collect a diverse dataset of high-quality course syllabi
2. Design a custom neural network architecture optimized for educational content structure
3. Develop specialized word embeddings for educational terminology
4. Create an evaluation framework for both technical and educational quality
5. Train and optimize the model through iterative refinement
6. Demonstrate practical application in a single educational domain

## **Proposed Research Design**

**Secondary Research:**

- Literature review of natural language generation approaches
- Analysis of neural architectures for structured text generation
- Exploration of domain-specific word embedding techniques
- Review of educational content quality evaluation methods

**Primary Research:**

- Gather and preprocess syllabi from open educational resources
- Design custom neural network with specialized layers for educational content
- Train using technical metrics and educational quality evaluation
- Test on multiple subject domains for generalizability

## **Artefacts to be Created**

1. Custom Neural Network Model for syllabus generation
2. Preprocessed Syllabus Dataset for research
3. Evaluation Framework for generated content quality
4. Interactive Demonstration System with web interface
5. Technical Documentation of architecture and implementation
