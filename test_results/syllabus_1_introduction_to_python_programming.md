## Learning Objectives

Upon successful completion of this course, students will be able to:

• Students will implement BFS and DFS algorithms in Python by writing complete functions that traverse adjacency lists and matrices
• Students will analyze time and space complexity of graph traversal algorithms through step-by-step trace exercises on sample graphs
• Students will implement BFS and DFS algorithms in Python by writing complete functions that traverse graph data structures and return appropriate results
• Students will analyze shortest path problems through hands-on application of Dijkstra's and Bellman-Ford algorithms to real navigation datasets

## Target Audience

Undergraduate students in Computer Science with appropriate prerequisites and foundational knowledge.
